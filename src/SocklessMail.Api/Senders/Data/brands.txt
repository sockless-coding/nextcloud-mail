# Domains that phishing imitates most, for the suspicious-sender checks (SenderIndex).
# One brand per line: its domains, the first one is what a warning names. "name.*" means the brand
# owns that name under many endings (amazon.de, amazon.co.uk, ...): a different ending is then not
# a look-alike. "~" marks a name that is also a common word: only look-alikes of it count, not
# other domains that merely contain it (orange-county.org). Only registered domains; subdomains of
# them count automatically.
#
